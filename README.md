# Spotify Popularity & Trends Analysis

## Overview
A Spotify analytics dashboard developed using Power BI to explore song popularity, artist rankings, and trends over time through an interactive visualization experience.

## Key Features
- Explicit vs. Non-Explicit Songs Analysis
- Artist Popularity Comparison
- Popularity vs. Song Position Scatter Plot
- Top 5 Artists Ranking Trends
- Total Song Count
- Average Popularity Score
- Music Performance KPIs

## Tools & Technologies
- Microsoft Power BI
- Data Analysis
- Data Visualization
- Dashboard Design
